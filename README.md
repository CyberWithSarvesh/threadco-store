## Features
- Browse products by category (Men, Women, Kids, Accessories)
- Search products by name/description
- Shopping cart with quantity update
- Order checkout saved to MySQL database
- Admin panel to add/delete products
- JSON API endpoint (/api/products)
- Logging, error handling, generators, list comprehensions

## Tech Stack
Python Flask, MySQL Workbench, Jinja2, HTML/CSS

## Setup
1. Run setup_db.sql in MySQL Workbench
2. pip install -r requirements.txt
3. python app.py
4. Visit http://localhost:5000
